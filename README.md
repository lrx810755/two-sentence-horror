A horror story told in exactly two sentences: **"I installed a camera to catch the thing moving my keys at night. Last night's footage shows me, asleep in bed, watching myself steal them."**

## Run

```sh
python3 main.py
```

Writes the two sentences to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
